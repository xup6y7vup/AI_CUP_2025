# AI CUP 2025 - Aortic Valve Object Detection (Computered Tomography)

This repository contains the source code for the **AI CUP 2025 Autumn Competition: Aortic Valve Object Detection**. The solution is based on the **YOLOv12** architecture implemented using Ultralytics and PyTorch, optimized for NVIDIA A6000 GPUs.

## Team Information
* **Team Name**: TEAM_9775
* **Model**: YOLOv12-X

## 1. Environment Setup

### Prerequisites
* Python 3.8+
* CUDA-enabled GPU (Recommended: NVIDIA RTX A6000 or similar)

### Installation
To set up the environment, please install the required dependencies using the following command:

```bash
pip install ultralytics torch torchvision torchaudio
Ultralytics: For YOLOv12 model implementation.

PyTorch: Deep learning framework with CUDA support.

2. Data Preparation
Please ensure the dataset is organized in the following structure before training. The labels.cache files are automatically generated by YOLO during the first run, but if you have pre-processed data, ensure the paths match.

Directory Structure:

Plaintext

Project_Root/
├── train.py                # Training script
├── predict.py              # Inference/Prediction script
├── aortic_valve_local.yaml # Data configuration file (optional if defined in code)
└── datasets/
    ├── train/
    │   ├── images/         # Training images (.png)
    │   ├── labels/         # Training labels (.txt)
    │   └── labels.cache    # (Auto-generated)
    └── val/
        ├── images/         # Validation images (.png)
        ├── labels/         # Validation labels (.txt)
        └── labels.cache    # (Auto-generated)
Note: The train.py script includes logic to organize raw patient folders into this structure if not already present.

3. Training
To train the model using YOLOv12x, run the following command. The script utilizes the datasets/train directory for training and datasets/val for validation.

Bash

python train.py
Configuration: The training is set to run for 150 epochs with a batch size of 4 (optimized for 48GB VRAM).

Output: Trained weights will be saved in runs/detect/aov_yolov12x_a6000_local/weights/best.pt.

4. Prediction / Inference
To generate predictions on the test set (or validation set) using the best-trained model:

Bash

python predict.py
Ensure that the best.pt model path is correctly referenced inside predict.py.

The results will be saved in the runs/detect/predict directory (or as defined in your script).
